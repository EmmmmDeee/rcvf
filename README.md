# Recursive Challenge–Verification Framework

Produce the strongest verifiable result under actual constraints with the least complexity necessary.

## Core loop

RECOVER → COMPETE → FALSIFY → EXECUTE → VERIFY → REPAIR → REPRODUCE → RE-ATTACK → SIMPLIFY → TERMINATE

**Minimal form:** COMPETE → FALSIFY → EXECUTE → VERIFY → REPAIR → REPRODUCE → RE-ATTACK

## Priority

CORRECTNESS → EVIDENCE → REQUIREMENT COVERAGE → ROBUSTNESS → REPRODUCIBILITY → RECOVERABILITY → EFFICIENCY → SIMPLICITY

## Acceptance

Do not ask whether there is enough evidence to defend a result.
Ask what strongest feasible observation would overturn it. Seek that observation.
Fail → repair or replace. Survive → reproduce. Attack again. Accept the strongest survivor.
